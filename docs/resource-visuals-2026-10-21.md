# Resource page visual learning update

The public catalogue and 45 web readers now show original explanatory SVGs, not just text and tables. Graphs use calculated coordinates; forces, cells, inheritance, radiation and river profiles use labelled diagrams; financial examples show amounts; other topics have connected evidence cards, timelines or language annotations derived from the published guide. These are simplified teaching aids, not reviewed scientific illustrations. Existing teacher/language review notices remain.

Readers show the illustration before numbered notes, include section shortcuts, and offer a native modal enlargement with keyboard Escape and a close button. Cards show a real illustration, time estimate and activity scope. The signed-in resource search, subject pages and curriculum library share a visual discovery shelf, with links to guides, resource search and the premium study assistant. Original guide results also show their specific diagram. A source-book shelf loads active publisher books from the database and opens them through the existing managed-file access. It shows actual counts, loading/retry/empty states and original titles. Official curriculum documents have a separate heading. No learning or publisher content is deleted or rebranded.

The new illustrations are web assets. Existing PDFs and their verified checksum manifest are unchanged, so PDF downloads still contain the previous tables/illustrations. Rebuild the SVG assets with `python scripts/content/build_visuals.py`. Do not run the initial publication SQL for this presentation-only update.

Live database audit on 21 October 2026: eight active publisher books, seven with indexed passages. Grade 10 Mathematics (educational resource 077e9c10-1490-4a40-a168-475e88b41faf) has zero indexed passages and needs indexing through the existing admin workflow. Other books have 543, 572, 691, 595, 744, 615 and 987 passages respectively (counts may change). No claim is made that every page has searchable text. The AI already retrieves learning knowledge; this update preserves that implementation and tells learners to check source/page references and distinguish document-grounded responses from web/general explanations.

Validation: unit tests, lint, typecheck, build; browser catalogue/filter/reader/answer/download flow at 360, 390, 768 and 1440 px, including diagram load and modal close/Escape. Production deployment must be checked separately before calling these changes live.
