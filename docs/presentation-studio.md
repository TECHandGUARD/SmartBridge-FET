# Presentation Studio

Administrators and verified tutors can open Presentation Studio from their dashboard. Tutors can also choose Make slides from this lesson in Lesson Studio to start a deck from the current plan. The transferred content stays in app navigation state; it is not put in a public link.

Create a blank presentation or start with an editable six-slide lesson outline. Add your own explanations and examples, switch among four themes, add or remove slides, reorder them and keep private speaker notes. The builder supports up to 40 slides. Save presentation stores the editable deck in your private account, so it can be reopened on another device. Revision checks prevent a stale browser tab from silently overwriting a newer save.

Every rendered slide has a high-contrast SmartBridge FET footer. Show author uses your account's full name and is optional; the branding cannot be disabled in the editor. The same renderer produces previews, live slide images and PDF exports. Speaker notes are excluded from slide images and exported PDFs. They are visible only in the author's editor or presenter view.

In a connected meeting or tutoring classroom, tutors and administrators can choose Build slides and then Save and present in this call, or Choose saved presentation to reuse a deck. Native deck page changes use the existing encrypted call transport and preserve audio/video. Imported PDF slides also receive a branding footer below the original page, with an optional account-name author line. Parents and learners receive the images but cannot access authoring controls or another account's stored decks.

Decks support text-based title and teaching-content layouts. PowerPoint/Canva files can be imported after exporting them as PDF. The lesson outline is a template, not AI-generated subject content: authors must supply and check their teaching material. This feature does not require a third-party slide-editor subscription. Call connectivity retains the existing direct WebRTC network limitations.
